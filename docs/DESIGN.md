# 设计文档 — 帆船航海模拟

> 对应「来自生活的游戏设计」方法论：现实航海过程 → 提取核心情感（与风对话、绝处逢生）→ 转化为游戏输入与挑战 → 航行体验。

## 一、核心体验

**真实航海模拟**。玩家通过转舵与调帆，在变化的风场中驾驭帆船。
核心张力在于：风是唯一的动力来源，但风不总在你要去的方向——
顶风区无法直行，必须走之字形（tack）；顺风时帆要完全放开；
正侧风最快但横倾最猛。**读懂风、调好帆、走对路**是玩法的全部。

## 二、物理模型

### 2.1 坐标约定

- 罗盘角度：0° = 北，顺时针递增（航海标准）
- Three.js 世界：0°(北) → -Z 方向；90°(东) → +X 方向
- 转换：`worldRad = -headingDeg × π/180`

### 2.2 风场（WindSystem）

- `direction`：风的**来向**（罗盘角），低频随机漂移 ±15°
- `speed`：风速（节），在 8~18 节间游走
- 平滑趋近目标，避免突变

### 2.3 帆的空气动力（SailPhysics）

输入：真实迎风角 TWA = 风向来向 − 船航向（归一化到 [-180,180]）

**效率曲线**（efficiency）：
| TWA | 状态 | 效率 |
|-----|------|------|
| <15° | 顶风失速 (in irons) | 0 |
| 15°~30° | 临界 | 线性回升 |
| 30°~45° | 抢风 close-hauled | ~0.5 |
| 90° | 正侧风 beam reach | 1.0（最高） |
| 135° | 偏顺风 broad reach | ~0.7 |
| 180° | 顺风 running | 0.6 |

**帆角匹配**（trim factor）：
- 最佳帆角 ≈ |TWA| / 2（顺风时帆放开到 ~90°，抢风时收到 ~22°）
- 玩家帆角偏离最佳值越远，trim factor 越低
- 偏离 45° 以上明显失速

**力分解**：
- `drive = totalForce × cos(|TWA|/2)`：沿船头方向的推力
- `side = totalForce × sin(|TWA|) × 0.5`：横向力
- 动压力 ∝ 风速² × 帆面积

**横倾（heel）**：侧向力使船倾斜，正侧风横倾最大，顺风反而直立。
横倾方向跟随 TWA 符号（风从左舷来 → 船向右倾）。

### 2.4 船体动力学（BoatDynamics）

- **推力 → 加速度**：`a = driveForce / mass`
- **水阻力**：`F_drag = k × v²`（典型流体阻力）
- **转向**：`turnRate = (rudder/maxRudder) × authority × (speed/6) × 30°/s`
  - 速度越高舵效越强；失速时几乎无法转向（符合真实）
- **位置积分**：节 → m/s → 世界单位

### 2.5 可调参数

所有物理参数集中在各模块的 `constructor`，便于平衡性调试：
- `boatMass`、`dragCoeff`、`rudderAuthority`、`maxRudder`
- `sailArea` 范围、`maxSailAngle`
- 帆力系数 `0.12`、横倾系数 `14`

## 三、操作设计

真实航海的核心操作映射到两个输入轴：

| 现实操作 | 游戏输入 | 物理影响 |
|---------|---------|---------|
| 转舵 | A/D | 舵角 → 航向变化率 |
| 调帆（trim） | W/S | 帆角 → trim factor → 推力 |
| 缩帆（reef） | Q/E | 帆面积 → 动压力 |
| 舵回正 | Space | 舵角归零 |
| 环顾四周 | 鼠标拖拽 | 相机环绕（不改变航向） |

**挑战设计**：玩家需要持续判断「当前航向 vs 风向」的关系，
随时调整帆角。走错航向（误入顶风区）会失速停滞；
调错帆角会白白浪费风力。这是「与风对话」情感原型的输入映射。

## 四、航行状态（Point of Sail）

系统实时计算并提示当前航行状态：
- No-Go / 顶风区（TWA < 30°）：无法航行，需转向
- Close-Hauled / 抢风（30~45°）：逆风走之字形
- Close Reach / 偏顺风（45~90°）
- Beam / Broad Reach（90~135°）：最快区间
- Running / 顺风（>135°）：帆完全放开
